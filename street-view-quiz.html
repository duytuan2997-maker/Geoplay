Kết nối Mapillary

Trò chơi tự kết nối bằng token đã cấu hình chung trên trang web. Nếu chưa cấu hình, bạn có thể nhập token riêng; token đó chỉ lưu trên thiết bị này.

Cách lấy Client Access Token
  1. Đăng nhập hoặc tạo tài khoản Mapillary.
  2. Đăng ký ứng dụng trong Mapillary Developer Dashboard.
  3. Sao chép Client Access Token vào tệp mapillary-config.js để mọi thiết bị tự kết nối. Nếu chỉ dùng trên thiết bị này, nhập token vào ô phía trên.

Token được gửi tới trình duyệt để gọi Mapillary API và hiển thị ảnh. Chỉ cấu hình token phù hợp để sử dụng trong ứng dụng web công khai.
